* Voltage callouts

Every printed voltage callout on the schematic, walked by eye. Spec V, Zone,
Subsystem, and Role are fixed reference data — fill in Measured V and % Diff
each session. % Diff = (Measured − Spec) / Spec × 100 — below spec is
negative, above is positive; easier to compare across rows spanning
fractions of a volt to hundreds of volts than a raw delta was. Subsystem
uses ZONES.org's named ranges; several zones straddle
two subsystems (noted where that happens) since the physical grid doesn't
respect circuit boundaries. Additional pins with no printed spec (most grids
and unmarked cathodes) aren't pre-populated here — add them as extra rows in
this same format when actually measured, same as 2026-08-15 did for V6.

Some Spec V entries are written as two numbers separated by a slash (e.g.
270/247) — per the schematic's own legend, top-right corner: "V — DC VOLTAGE
AM/FM, ALL VOLTAGE ARE MEASURED WITH VTVM." These are two distinct readings
depending on which mode the receiver is in when measured (different
tubes/stages active, different B+ loading), not a range or tolerance. Order
matches the legend: AM first, FM second. Compare your measurement against the
half matching the session's actual Mode condition above, not just whichever
number looks closer.

- Row 31 topology (C82/R101/R98/C67+ junction) :: reading the
  schematic directly, 2026-09-08 — R87 sits between C66+ and C67+
  (both caps' negatives grounded), stepping down from row 31's
  junction to row 32's. R101 sits *between* two separate nodes, not
  inside one shared junction as first thought: one side is a
  "super-junction" shared by T5 pin 4, V12 Pin 6, R97, and C80 — this
  is the same node as row 26 (V12 Pin 6, spec 50V), not part of row
  31. R101's *other* side is row 31 itself (150V spec), continuing to
  C82+/R98/C67+. R98 (6k, 6W) continues from row 31's node toward
  another point further downstream, also marked ~150V with 15mA/16mA
  current arrows.
  This whole branch (row 26 and row 31 both) reads ~0V when the
  selector is on AUX and comes up to sensible values (41.89V / 107.9V
  respectively, both a reasonable fraction of spec) when switched to
  FM — this branch is FM-specific and simply unpowered outside FM
  mode, not a fault. See 2026-09-08 measurements for the full story;
  this was mistaken for a possible open B+ feed before the mode
  dependency was found. V14 (rows 29-30, AM section) showed the exact
  same pattern — ~0V on AUX, healthy readings (115.1V/72.9V) once
  switched to AM.
- AUX and AM/FM section power :: confirmed 2026-09-08 — selecting AUX
  doesn't just reroute the signal path, it leaves BOTH the AM section
  (V14) and at least part of the FM section (V12/T5 branch, rows
  26/31) completely unpowered, not just switched out of circuit. Any
  AM- or FM-tagged row in this table will read near 0V on AUX and
  isn't a fault — test those rows in their own mode (AM or FM
  respectively), not AUX, or a perfectly healthy section will look
  like an open B+ feed. Worth setting Mode to AM or FM rather than AUX
  whenever this table's AM/FM-zone rows matter for a session.

* Observations

Hum, drift, anything that changed as it warmed, smell, visible arcing, how the
dim bulb behaved.

Full mains, no bulb. Most rows landed within roughly ±15% of spec —
a healthy pattern overall, and a big improvement over the dim-bulb
pass's uniform ~-30%/-50% sag. Several real standouts worth attention
rather than filing away as normal spread:

- V4 Pin 6 :: 197.6V against an 85V spec (+132.5%) is not a new
  finding — this pin has been a documented, worsening outlier since
  2026-08-15 (105V that session, 118.7V later, now 197.6V). The trend
  is getting worse each time it's checked, not stabilizing. Its exact
  schematic position was already flagged as uncertain (zone inferred,
  the "85V" label sits ambiguously between V4's two sections) — this
  needs actual investigation, not just another data point added to
  the pile.
- V6-V9 Pin 3 (shared cathode via C600) :: swung from -98% (0.205V)
  under the dim bulb to +79.7% (19.77V) at full power — a huge
  reversal, not just "now it's warmed up." Under-heated tubes reading
  near-zero cathode current made sense; conducting *far more* than
  spec at full power is a different question and worth understanding,
  not assuming away.
- C101-/C102+ :: retracted — 181.9V looked like a jump from the
  ~106.7V this node hit twice before, but that compared absolute
  values across sessions with different overall B+ levels. The right
  check is the doubler symmetry ratio: C101+ measured 364.2V this
  pass, and 181.9/364.2 = 0.4994 — essentially exactly half, matching
  the 0.4977 ratio from the 2026-09-10 post-replacement check (214.5V
  / 106.7V). The midpoint scaled up in lockstep with C101+, which is
  the correct healthy doubler behavior, not a fault.
- V14 Pin 6 :: -0.9V against an 82V spec — RESOLVED, not a fault.
  Mode was AUX this pass, and the existing notes above already
  document that AUX leaves the AM section (V14) completely unpowered,
  reading near 0V — exactly what -0.9V is. Original "strange" flag
  retracted.
- C100 Pin 2 vs Pin 1 :: retracted — this comparison was based on a
  wrong assumption that Pin 1 (screen decoupling, via R65/R66) is in
  series with the R117→Pin2→R116→Pin3 cascade. It isn't; it's a
  parallel branch off the same raw rail. Judged against each pin's
  own spec instead, both read moderately high (see below), consistent
  with the session's general pattern, not a topology violation.
- Mode was AUX for this whole pass, not AM or FM — worth flagging
  since C100 Pin 2/Pin 3's dual AM/FM spec values (296/280 and
  270/247) don't have a documented AUX equivalent; the % Diff figures
  above use AM or FM as an imperfect proxy, not a true AUX spec. A
  follow-up pass in FM (in progress) will give a real comparison.
- C100 Pin 2/Pin 3 follow-up, correct mode comparison :: switched
  modes to resolve the AUX ambiguity above. FM stereo: Pin 2 = 298.1V
  (spec 280V, +6.5%), Pin 3 = 266.6V (spec 247V, +7.9%). AM: Pin 2 =
  316.7V (spec 296V, +7.0%), Pin 3 = 293.8V (spec 270V, +8.8%). Both
  modes land in a tight, consistent +6.5% to +8.8% band — healthy,
  no red flags, and confirms the earlier AUX-mode readings for these
  two rows genuinely weren't comparable to either spec value.
- V14 Pin 5/Pin 6 follow-up, AM mode (V14's actual active mode) ::
  Pin 5 = 175V (spec 160V, +9.4%), Pin 6 = 99.6V (spec 82V, +21.5%).
  Both sensible once properly powered — confirms the earlier -0.9V
  AUX reading really was just "unpowered," not a fault, same
  conclusion as C100's mode follow-up above.
- V12 Pin 6 :: 53.4V measured, but the existing notes above document
  this exact row reading ~0V on AUX (same unpowered-on-AUX behavior
  as V14/AM). A real reading here while allegedly in AUX mode
  conflicts with that documented behavior — worth resolving rather
  than ignoring. Possible explanations: the switch wasn't fully
  engaged when this particular reading was taken, or the 2026-09-08
  finding needs re-verification. Not immediately concerning, but a
  genuine inconsistency, not just more spread.

V1 Pin 3 came back to 0.574V (essentially in spec) at full power,
after reading a flat 0V under the dim bulb — consistent with that
being a cold/under-heated artifact rather than the long-standing V1
socket fault reasserting itself, though that thread is still worth
closing out properly rather than assuming this one clean reading
settles it for good.
