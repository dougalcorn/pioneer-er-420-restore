#+TITLE: ER-420 Voltage Readings — YYYY-MM-DD
#+STARTUP: overview

Copy to =measurements/YYYY-MM-DD-voltages.org= each time you power up and take
readings. On a variac brought up slowly, with a dim bulb limiter in line.
Record conditions — these numbers are worthless without them.

* Conditions

- Date ::
- Line voltage at the outlet ::
- Variac setting ::
- Dim bulb ::
- Warm-up time before reading ::
- Meter ::
- Reference point for all measurements ::
- Mode (AM/FM) :: which mode the receiver was actually set to —
  several spec values below are dual AM/FM readings, and this decides
  which half of the pair applies

* Voltage callouts

Every printed voltage callout on the schematic, walked by eye. Spec V, Zone,
Subsystem, and Role are fixed reference data — fill in Measured V and % Diff
each session. % Diff = (Measured − Spec) / Spec × 100 — below spec is
negative, above is positive; easier to compare across rows spanning
fractions of a volt to hundreds of volts than a raw delta was. Subsystem
uses ZONES.org's named ranges; several zones straddle
two subsystems (noted where that happens) since the physical grid doesn't
respect circuit boundaries. Additional pins with no printed spec (most grids
and unmarked cathodes) aren't pre-populated here — add them as extra rows in
this same format when actually measured, same as 2026-08-15 did for V6.

Some Spec V entries are written as two numbers separated by a slash (e.g.
270/247) — per the schematic's own legend, top-right corner: "V — DC VOLTAGE
AM/FM, ALL VOLTAGE ARE MEASURED WITH VTVM." These are two distinct readings
depending on which mode the receiver is in when measured (different
tubes/stages active, different B+ loading), not a range or tolerance. Order
matches the legend: AM first, FM second. Compare your measurement against the
half matching the session's actual Mode condition above, not just whichever
number looks closer.

Notes:
- Between R21 and R17 :: also common with C11+ and R23, which land in
  zone F4 (Selector switch's C1-G7 range) — a different subsystem than
  this node's own D4 (Tone/preamp). Worth remembering if tracing this
  net physically; it crosses a subsystem boundary.
  Role corrected 2026-09-08, reading tile-C3-E5 directly plus physical
  tracing at the bench: this is V1's 110V bias-supply bus, not "V1
  sec. 2 cathode area" as originally guessed. R21 (100k) is section
  2's plate load (ties to pin 6/C9); R17 (250k) ties into this same
  110V bus, confirmed by tracing; R19 (2.2M, previously unclear
  whether cathode or grid-leak) confirmed grounded — it's pin 7's
  grid-leak resistor, which also fits its value far better than a
  cathode resistor would (2.2M would bias a 12AX7 essentially off).
- V4 Pin 6 :: zone filled in from the 2026-08-15 log (C10), not from
  this pass — the log flagged its exact schematic position as
  uncertain (the "85V" label sits between V4's two triode sections).
  Also the one outlier reading so far: measured 105V against this
  85V spec on 2026-08-15, running *above* spec rather than below like
  everything else that session. Not yet resolved.
- V4 Pin 8 :: zone inferred as matching V4's other pins (D10), not
  independently confirmed.
- V6-V9 Pin 9 :: this 300V callout corrects the 2026-08-15 measurements
  file, which said "not on schematic as a distinct spec" for the
  screen grid (181V measured that session, now ~60% of this real spec
  rather than an unscaled reading — consistent with the rest of that
  session's B+ chain proportions, not an outlier after all).
- C99/C100 sections :: "40µF+," "20µF+" labels refer to the discrete
  rebuild's section values per component-notes.org, not necessarily
  the physical tap order on the can.
- C100 pinout :: read directly off the can's own labeled pins,
  2026-09-08 — pin 1 = 40µF+ section (row 17, screen-decoupling node
  per component-notes.org — inferred by elimination, not
  re-independently confirmed this session), pin 2 = 20µF+ section
  between R116/R117 (row 19), pin 3 = 20µF+ section, R116-fed (row
  18), pin 4 = common/ground (black wire). C99's pins are not labeled
  the same way and remain unidentified per-lug.
- C99 (20µF+, near R104) and C101 :: zones are inferred/approximate,
  not directly confirmed the way most of this list was — worth a
  closer schematic check if precision here matters later.
- C99 pinout :: pin 4 = ground (confirmed by continuity, 2026-09-08,
  matching C100's convention). Pin 2 = the 205V section (row 15) —
  traced 2026-09-08 via continuity from V3 Pin 1 through a 100kΩ
  resistor to this pin; that resistor matches R38's value and position
  (tile-E7-G9, adjacent to this section's "1" label on the schematic —
  inferred, not independently confirmed as R38 by designator). "Near
  R81" in the row label was a proximity guess and appears wrong; R81
  is a 10k resistor in an unrelated switch section per bom.org. Pins 1
  and 3 matched 2026-09-08 by voltage magnitude, not by tracing: pin 1
  = row 14 (230V section, 156.5V measured, 0.68 ratio), pin 3 = row 16
  (110V section, 91.8V measured, 0.84 ratio) — the reverse assignment
  doesn't fit (would put one section's reading above spec, unlike
  every other reading that session). Row 16's "near R104" label is
  still unconfirmed by tracing, same caveat as before — only the pin
  number is new.
- H-column entries (row 31's C82/R101/R98/C67+ junction, row 32's
  C66+/R87) :: H5-H8 and H6 don't fall cleanly into any of ZONES.org's
  named subsystem ranges. C64/R86 (H4) does land in FM front end's
  range (G-H, 1-5). Row 31 was originally mislabeled "C81 and C67" —
  corrected 2026-09-08, see notes; C81 is a real, different component
  elsewhere, not part of this junction.
- AM/FM overlap entries (V10, V12) :: ZONES.org already documents that
  AM section and FM front end share drawn space; several zones here
  genuinely belong to more than one subsystem rather than one being
  wrong.
- V13 :: matches V12 exactly (same 50V spec on both pins, same zone) —
  the two tubes are a paired pair (schematic tile G7-I9 marks "50V" at
  both), consistent with V12/V13 sharing this stage's design.
- C75, S1 1/4, R85 :: zone I4-I6 mostly falls in AM section's range
  (G-I, 1-5), with I6 spilling just outside it; also plausibly
  Selector-switch-adjacent given S1's involvement. Not independently
  confirmed against a schematic tile.
- V14 Pin 5, Pin 6 :: resolved — bom.org's H9 was wrong, corrected to
  H3 (matches this callout pass, not the stale BOM entry). Another
  entry in the project's track record of wrong zone data (C88,
  C11/C12) turning out to matter. Roles not identified yet; 160V/82V
  could plausibly be plate/screen or oscillator-section pins on this
  heptode, but that's a guess, not a trace.
- Row 31 topology (C82/R101/R98/C67+ junction) :: reading the
  schematic directly, 2026-09-08 — R87 sits between C66+ and C67+
  (both caps' negatives grounded), stepping down from row 31's
  junction to row 32's. R101 sits *between* two separate nodes, not
  inside one shared junction as first thought: one side is a
  "super-junction" shared by T5 pin 4, V12 Pin 6, R97, and C80 — this
  is the same node as row 26 (V12 Pin 6, spec 50V), not part of row
  31. R101's *other* side is row 31 itself (150V spec), continuing to
  C82+/R98/C67+. R98 (6k, 6W) continues from row 31's node toward
  another point further downstream, also marked ~150V with 15mA/16mA
  current arrows.
  This whole branch (row 26 and row 31 both) reads ~0V when the
  selector is on AUX and comes up to sensible values (41.89V / 107.9V
  respectively, both a reasonable fraction of spec) when switched to
  FM — this branch is FM-specific and simply unpowered outside FM
  mode, not a fault. See 2026-09-08 measurements for the full story;
  this was mistaken for a possible open B+ feed before the mode
  dependency was found. V14 (rows 29-30, AM section) showed the exact
  same pattern — ~0V on AUX, healthy readings (115.1V/72.9V) once
  switched to AM.
- AUX and AM/FM section power :: confirmed 2026-09-08 — selecting AUX
  doesn't just reroute the signal path, it leaves BOTH the AM section
  (V14) and at least part of the FM section (V12/T5 branch, rows
  26/31) completely unpowered, not just switched out of circuit. Any
  AM- or FM-tagged row in this table will read near 0V on AUX and
  isn't a fault — test those rows in their own mode (AM or FM
  respectively), not AUX, or a perfectly healthy section will look
  like an open B+ feed. Worth setting Mode to AM or FM rather than AUX
  whenever this table's AM/FM-zone rows matter for a session.
