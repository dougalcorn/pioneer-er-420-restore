Notes:
- Rectifier out (row 20) :: confirmed via continuity from this
  terminal to D3, matching component-notes.org (D3 lands on C101's
  "+").
- C101/C102 midpoint :: not in the master callout list — kept for the
  record since it was measured alongside rectifier-out and confirms
  the doubler's internal ratio looks healthy (~2:1, roughly matching
  194:93).
- Row 19 (After R117) :: ~62-64% of spec, proportionally consistent
  with rectifier-out's ~57% — dim-bulb suppression, not a localized
  fault.
- Row 18 (After R116) :: 185V against 270/247V spec is ~69-75% of
  spec — a bit higher proportionally than the other two readings
  (57-64%) but still broadly in the same range; not alarming on its
  own, worth keeping in mind if the pattern diverges further once
  more of the chain is measured.
- Row 12 (screen supply, C100 3rd section) :: this is the "4th pin"
  open question from the 2026-08-11 gray-cap log, now resolved.
  Confirmed by continuity to V6/V7/V8/V9 pin 9 — the screen grid (g2),
  per the real B9A pinout for 6BQ5/EL84 (r-type.org), not plate as
  first guessed — a separate C100 section, fed via R65/R66 (2.5k) from
  the main rail rather than through R116/R117. Written up in
  component-notes.org's C100 entry. Originally logged here as having
  no distinct schematic spec; TEMPLATE.org's full callout walk on
  2026-08-17 found one (300V, printed near V9). 181V against that spec
  is ~60% — consistent with the rest of this session's B+ chain
  proportions (57-75%), not an unscaled outlier after all.
- Row 11 / V1, V6-V9 (shared) :: C600 shared cathode-bias node, pos
  side to chassis. Neg side of C600 shows continuity with chassis (as
  expected). C600 itself isn't on the schematic, but the node it
  bridges (V6 pin 3) is, marked 11V there. Measured value is only ~9%
  of that spec — a much bigger proportional drop than the B+ chain
  readings (57-75% of spec), consistent with tube current dropping off
  nonlinearly as B+ is suppressed by the dim bulb tester, not a fault.
  Don't scale this one proportionally to estimate the full-power value
  the way the B+ readings reasonably can be — reading taken under
  dim-bulb-limited conditions; expect this to rise once measured at
  full B+ without the bulb, and not linearly. Not yet the number to
  size C600's replacement voltage against.
- V6 full pin sweep :: real B9A pinout for 6BQ5/EL84 confirmed via
  r-type.org after some back-and-forth misreading the schematic's tiny
  pin-position print (see 2026-08-15 log for the full story). Pins 1,
  6, 8 read empty — these are cathode/g3 internal ties, not stray NC
  pins; this circuit only wires that connection out externally on pin
  3 (where C600 lands), leaving the redundant tie points unconnected
  at the socket. Pins 2 and 3 (grid, cathode) only showed ohms on the
  auto-ranging DMM rather than a clean voltage — both are very
  low-voltage nodes (grid near ground, cathode ~1V per row 11),
  plausibly why the meter fell back to resistance mode. Pins 4 and 5
  (1.58V, 1.97V) are heater, confirmed by the pinout reference. Pin 7
  is plate (200V against 335V spec, delta -135, ~60% of spec —
  consistent with the rest of today's B+ chain).
- Row 13 / Pin 9 across V6/V7/V8/V9 :: this is screen grid (g2), not
  plate as first assumed — all four tubes' screens share one common
  node, fed from C100's third section (R65/R66). All four reading the
  same 181V and showing continuity to each other is normal: unlike
  plates, which need to be split out-of-phase across the output
  transformer primary for push-pull operation, screens have no such
  requirement and can share one common supply across all four tubes
  without issue. This also resolves the "4th pin" open question from
  2026-08-11 — that section decouples the screen supply, not the
  plate.
- V4 :: pin identities here are read directly off the tube socket
  (physically keyed, unambiguous), not inferred from the schematic
  drawing the way V6's pins were — standard 12AX7 pinout (pin 1/6 =
  plate sections 1/2, pin 7 = grid section 2, pin 8 = cathode section
  2) trusted without needing a resistor trace to confirm it. Two
  things stand out: pin 6 (105V) reads *above* its 85V spec rather
  than below like every other reading today (TEMPLATE.org's callout
  walk pins this spec's zone to C10 but flags the exact position as
  uncertain — the "85V" label sits between V4's two triode sections).
  And pins 7/8 imply roughly a -21V grid-to-cathode bias, large for a
  12AX7. Reading this the same way as C600's disproportionate drop:
  this stage's bias network depends on actual current flow, which is
  heavily suppressed on the dim bulb tester, so this isn't necessarily
  a fault — it may just not be meaningful data yet. Worth rechecking
  at full B+ before drawing any conclusion about this stage.
- V10, V11 :: both plate readings land at ~89-90% of spec (76/85V,
  78/87V) — notably closer to nominal than the output/preamp stages
  (57-75%). Consistent with each other, which supports a real pattern
  rather than coincidence: these are light-current RF/IF pentodes, so
  under the shared dim-bulb current limit they recover closer to
  nominal while the heavier-current output stage sees a bigger drop.
- V12 :: session ended before this was resolved. DMM's auto-select
  showed no voltage on any pin. Not yet determined whether the tube is
  well-seated, whether its heater is visibly lit, or whether this is a
  true 0V-everywhere reading versus the meter failing to settle. Needs
  follow-up next session before drawing any conclusion — carried
  forward to the log's Open questions.
- V13 :: pin 5 (plate) at 45V against 50V spec (~90%) matches the
  V10/V11 light-current pattern above. Pin 6 (screen grid, g2) reading
  the identical 45V is unexplained — worth a continuity check between
  pins 5 and 6 to see if they're genuinely tied together in this stage
  or just coincidentally matching at this operating point. Not yet
  checked.
