Second half of the session: worked through options for adding a
second AUX-equivalent input (currently want to run a turntable through
a dedicated Schiit Mani 2 phono preamp *and* a WiiM streamer, but only
have one AUX jack). Ruled out feeding either into PHONO MAG, PHONO
CER/X-TAL, or TAPE HEAD directly — all three are low-level inputs
(1.8-29mV) built for raw, unamplified sources feeding the shared V1/V2
gain stage; a line-level signal (~200mV+) into any of them would
overdrive that stage or hit EQ it doesn't need. Looked at both manual
external RCA selectors and signal-auto-sensing switchers (the latter's
real drawback: they detect based on signal presence, so quiet
passages/gaps between tracks can cause an audible flip-away-and-back).
Searched for period-style options too, both new-made-to-look-vintage
and genuine period units (RadioShack/Realistic Tape Control Center,
Russound TMS-1) — the honest tradeoff there is that a real vintage
selector box is itself 40-50 years old and likely needs the same
contact-cleaning care the ER-420 did, not zero-maintenance despite
looking the part.

Pulled up [[file:../schematic/tiles/tile-C1-E3.png][tile-C1-E3.png]] to actually look at the input jack column
and S1's first wafer directly, rather than reasoning from memory.
Confirmed the six jacks there (TAPE REC, TAPE MONITOR, AUX, TAPE HEAD,
PHONO MAG, PHONO CER/X-TAL) are three different functions, not six
variations on "input": TAPE REC is actually an *output*, tapped
post-selector pre-volume, feeding a deck's record input; TAPE MONITOR
is the matching input for a deck's own playback output, working with
S3 (Tape Monitor ON/OFF, logged separately in bom.org) to A/B source
vs. tape; AUX is generic line level; the two PHONO jacks serve
different cartridge types (magnetic needs RIAA EQ, ceramic/crystal is
largely self-equalizing and would get the wrong tonal balance through
the mag path); TAPE HEAD is a raw tape-head signal for a deck with no
onboard preamp of its own.

That makes TAPE MONITOR the promising candidate for the second
line-level input — it's built to accept an already-amplified,
already-equalized external device's output, no different in job from
AUX, and using it costs no chassis modification at all. Confirmed via
the schematic tile that TAPE MONITOR lands on the same S1 wafer as the
other jacks, sharing the wiper bus into V1's grid. What's *not*
confirmed: whether S3 has to be in a specific position for that S1
selection to actually pass signal through, or whether S3 does
something unrelated. Not traced — flagged as something to test live
rather than resolve from the diagram.
