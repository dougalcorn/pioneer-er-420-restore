#+TITLE: Schematic extraction and gridding — 2026-07-28
#+DATE: 2026-07-28
#+FILETAGS: :audio:restoration:er420:

* Goal

Extract the schematic at full resolution, grid and tile it for
reference, and check the service manual for anything else worth
pulling out before retiring it from active use.

* Work

Cropped page 2 of the manual to just the schematic in Preview and
exported to =schematic/raw/er-420-schematic.png=. Checked the PDF's
embedded scan with =pdfimages -list= first — native 600 PPI, so that's
the true resolution ceiling, not a guess. Came out 5623 x 4061px.

=scripts/grid.sh= failed on a fresh ImageMagick install — no font
database registered at all. Fixed by pointing =-font= at a real font
file directly instead of relying on name resolution.

Picked 12 x 9 (cell 468 x 451px), validated against =tiles.sh='s
~1500px downsample ceiling before running rather than after. Ran
=grid.sh=, then =tiles.sh= with its 3x3-cell/stride-2 defaults — 20
tiles, 1404 x 1353px each. Spot-checked one; every value and
designator reads cleanly at full resolution.

Reading the grid legend resolved S9 — line voltage selector
(115V/230V), confirmed directly rather than left as a guess. Updated
bom.org.

Reviewed the rest of the manual for completeness. Parts lists and
alignment procedures are fully covered already (bom.org, and
correctly excluded per the RF/MPX scope decision). Pulled the power
circuit and audio circuit troubleshooting tables into
troubleshooting.org — the only in-scope content that wasn't captured
anywhere yet.

Walked all 24 tiles (the original 20 plus 4 supplementary — tiles.sh's
coverage math never reaches the last column at 12 cols/3-cell
tiles/stride 2, patched with direct crops rather than changing the
script's defaults) and filled in ZONES.org's subsystem table with
real zones. Two findings worth more than a table cell: "Phono EQ"
isn't a distinct block — the phono jacks feed a plain resistor divider
straight into the shared preamp, no RIAA network to point to — and S1
(input selector) is drawn in four disconnected wafer sections spanning
nearly the whole sheet (C1-G7), not one zone.

Created =schematic/circuit-notes.org= for subsystem-level findings —
one heading per subsystem, same list as ZONES.org's table, so the
index stays lean (zones/board only) and the actual tracing notes live
somewhere consolidated instead of fragmenting into a file per
subsystem. Moved the Phono EQ and S1 findings there, plus general
background on what RIAA equalization is and how it's typically
implemented (frequency-dependent feedback around a gain stage, not a
passive filter) — reference material for whenever phono work resumes.

Looked closer at F8-F12 specifically (right-channel driver/output
decoupling — V4/V5 phase inverter and V8/V9 bias networks, the second
poles of S5/S6/S7/S8). Caught myself misreading a 20µF/350V cap there
as C99 — it's C98, an easy 8/9 misread at this print size. Also
noticed C99's three sections (40+20+20µF) may land at three different
points along the B+ dropping-resistor chain (R111→R112/R113→R114/
R115→R116/R117) rather than one shared node — not confirmed, but
directly relevant to the discrete rebuild if true. Corrected Driver
and Output stage zones in ZONES.org to extend into column F, which
the original walk had missed.

Decided against curated crops in =schematic/sections/= — the
generated tiles already cover everything at a legible size, so
copying them into a second directory under new names would just be
duplicate pixels on disk. Pointed ZONES.org's subsystem table at the
relevant =tiles/= filenames directly instead (as proper org
=[[file:]]= links), noting where Driver and Output stage share the
same tiles since they're adjacent stages on the same rows. Phase -1
is done — 8/8.
